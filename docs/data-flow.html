How a RADET becomes the live dashboard

You drop one file into a folder. Everything after that runs by itself, and patient-level data never leaves your computer.

Your part

Save the new RADET export into C:\Users\user\ViiV_Python_M&E\RADET_inbox. Any file name works, as long as it is .xlsx. If you drop several at once, only the newest is used.

What runs automatically

  • The watcher waits until the file has finished copying.
  • The analysis builds the indicators and the Excel report.
  • The sanitizer strips patient records, then the result is pushed.
  • Netlify rebuilds the site and open dashboards pick up the new numbers.

What stays private

Client records, hospital numbers, patient IDs and case manager names stay in data-private\. That folder is excluded from git, and the sanitizer refuses to publish if any of those fields slip through.

If the site doesn't update

  • Open watch_radet.log to see which step failed.
  • A file in RADET_inbox\failed\ means the analysis could not read it.
  • No Python window in the taskbar means the watcher isn't running. Start ViiV RADET Watcher from the Startup folder.
